validityTamperingAttack :: (Members '[Tweak, NonDet] effs, Is k A_Traversal, Foldable f, Alternative f) => ValidityTamperingParams a f k is -> Sem effs SlotRange Source #

The validity tampering attack attempts to tamper with the validity interval of a transaction following a given set of parameters. This returns the validity interval of the transaction before modification.
